# Contributing to System Design Lab

Please keep each experiment self-contained and place changes in the correct version folder.

## Guidelines
1. Use clear file and folder names.
2. Keep hardware files, firmware, data, analysis and results separated.
3. Document major design changes between V1, V2 and later versions.
4. Do not commit passwords, API keys, private credentials or sensitive participant data.
5. Add a short README when introducing a new experiment or major component.
6. Prefer concise commit messages that describe the actual change.
7. Store common resources under `Common-Resources/` only when they are used by more than one experiment.

## Suggested version structure
```text
V1/
├── Hardware/
├── Firmware/
├── Dataset/
├── Analysis/
├── Results/
└── Documentation/
```
