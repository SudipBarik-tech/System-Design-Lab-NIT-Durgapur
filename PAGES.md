# GitHub Pages

The website entry point is `index.html` in the repository root and `.nojekyll` is included.

To publish the site, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Expected public URL after GitHub Pages is enabled:

`https://sudipbarik-tech.github.io/System-Design-Lab-NIT-Durgapur/`
